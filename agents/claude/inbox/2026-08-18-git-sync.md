## Что нужно сделать

Установить фактическое расхождение локального репозитория и `origin`, свести
локальные ветки со свежим `main` и предъявить состояние открытых PR и
удалённых веток: что влито, что отстало, что можно удалять.

## Границы

Не пушить, не мержить PR, не удалять удалённые ветки без отдельного
подтверждения владельца. Не трогать ветки других агентов
(`antigravity/*`, `codex/*`, `hermes/*`). Не править документацию —
рассинхрон CHANGELOG/README/roadmap с фактическим состоянием релизов
вынесен из этой задачи и идёт в отчёт списком.

## Как проверить результат

- `git fetch --all --prune` — выполнен;
- `git rev-parse main origin/main` — совпадают;
- `git log --oneline HEAD..origin/main` — пусто (нечего вливать);
- `git branch -r --merged origin/main` — список влитых веток приведён в отчёте.
